# Project Overview

Creating a Gymnastics App (PWA) where the user can log in, create and host a gymnastics meet all in one place! I would like the user to be able to save data to their local computer if WiFi is to ever be interupted.

# Tech Stack

- Database - Postgres(production) and sqllite(dev testing)
- Backend - Python with FASTAPI
- Frontend - React JS
- Styling - Tailwind CSS, DaisyUi
